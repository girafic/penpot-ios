Spezifikation Ihrer Designs, Änderungen in Echtzeit, die Bibliothek einer Datei und mehrere Konten.

• Spezifikation, wie im Ansichtsmodus von Penpot: Tippen Sie auf eine Ebene, um Größe, Position und Abstände zu sehen, dazu Flächen, Rahmen, Schatten, Weichzeichnen und Typografie sowie das CSS. Jeder Wert lässt sich mit einem Tippen kopieren.
• Live: Solange eine Datei geöffnet ist, erscheinen Änderungen anderer in Penpot nach wenigen Sekunden, und Sie sehen, wer die Datei gerade noch geöffnet hat. Kommentare aktualisieren sich von selbst.
• Assets: Sehen Sie die Komponenten, Grafiken, Farben und Typografien einer Datei und ihre Design-Tokens nach Set, aufgelöst für die aktiven Themes. Öffnen Sie eine Komponente wie eine Zeichenfläche, oder kopieren Sie eine Farbe, das CSS einer Typografie oder den Wert eines Tokens.
• Mehrere Konten: Fügen Sie Konten auf design.penpot.app oder Ihrem eigenen Server hinzu und wechseln Sie ohne neue Anmeldung zwischen ihnen.
• Präsentieren auf dem großen Bildschirm: Schließen Sie einen Bildschirm an oder nutzen Sie AirPlay-Bildschirmsynchronisierung. Dort läuft der Prototyp in voller Größe, während Sie ihn auf dem iPhone durchtippen.
• Auf breiten Bildschirmen, etwa beim iPhone im Querformat, stehen in der Zeichenflächen-Ansicht die Zeichenflächen der Seite daneben, und die Spezifikation rückt zur Seite.
