# Support

Mit **Viewer for Penpot** sehen Sie Penpot-Designdateien auf dem iPhone an, prüfen und
kommentieren sie. [English]({{ '/support/' | relative_url }})

## Voraussetzungen

- Ein iPhone mit iOS 17 oder neuer.
- Ein Penpot-Konto, entweder auf `design.penpot.app` oder auf einem selbst gehosteten
  Penpot-Server. Penpot ist kostenlos und Open Source; ein Konto erstellen Sie auf
  [penpot.app](https://penpot.app).

## Fragen und Antworten

**Kann ich in der App Designs bearbeiten?**
Nein. Die App ist zum Ansehen, Prüfen und Kommentieren da. Zum Zeichnen und Bearbeiten
nutzen Sie Penpot auf dem Computer. Alles rund um das Design können Sie in der App aber
ändern: Dateien, Projekte, Teammitglieder, Schriftarten, Versionen und Freigabe-Links.

**Wie nutze ich meinen eigenen Penpot-Server?**
Geben Sie auf dem Anmeldebildschirm die Adresse Ihres Servers im Feld „Penpot-Server“ ein,
zum Beispiel `https://penpot.example.com`. Server ohne HTTPS funktionieren auch.

**Ich kann mich in der App nicht registrieren oder mein Passwort zurücksetzen.**
Auf `design.penpot.app` schützt Penpot diese Seiten mit einer Browser-Prüfung. Die App
öffnet dann Penpots Website, wo Sie die Registrierung oder das Zurücksetzen abschließen.
Danach melden Sie sich in der App an.

**Eine Zeichenfläche sieht anders aus als in Penpot.**
Die App zeichnet Zeichenflächen auf dem iPhone aus den Daten der Datei, nach dem Vorbild von
Penpots eigenem Renderer. Einige Effekte fehlen noch, etwa Pfeilspitzen an Linien. Melden
Sie den Unterschied bitte mit einem Bildschirmfoto (siehe Kontakt unten). Einstellungen →
Über → **Bild-Cache leeren** zeichnet alle Zeichenflächen neu.

**Der Export einer Zeichenfläche als Bild schlägt fehl.**
Der Export als PNG, JPEG, WebP, SVG oder PDF nutzt den Export-Dienst Ihres Penpot-Servers.
Selbst gehostete Server haben ihn nicht immer. Zum Ansehen der Zeichenflächen wird er
nicht gebraucht.

**Warum zeigt der Kommentar-Eingang nur ungelesene Threads?**
Penpot listet teamweit nur ungelesene Threads auf. Öffnen Sie eine Datei, um alle ihre
Kommentare zu sehen, auch gelesene und erledigte.

**Auf meinem eigenen Server fehlen Funktionen.**
Einige Funktionen brauchen eine aktuelle Penpot-Version:
- Import: 1.15;
- Vorlagen: 1.19;
- Versionsverlauf: 2.4;
- @-Erwähnungen: 2.7;
- „Zuletzt gelöscht“: 2.12;
- Hochladen von Schriftarten: 2.17.

**Wie lösche ich mein Konto?**
Einstellungen → Profil → **Konto löschen**. Damit wird Ihr Penpot-Konto auf dem Server
gelöscht, bei dem Sie angemeldet sind. Siehe auch die
[Datenschutzerklärung]({{ '/de/datenschutz/' | relative_url }}).

**Welche Sprachen gibt es?**
Dieselben 34 Sprachen wie in Penpot. Die Sprache stellen Sie auf dem Anmeldebildschirm
oder unter Einstellungen → Erscheinungsbild ein.

## Kontakt

Fehler und Ideen melden Sie bitte unter
[github.com/girafic/penpot-ios/issues](https://github.com/girafic/penpot-ios/issues).
Nennen Sie dabei bitte Ihr iPhone-Modell, die iOS-Version, die App-Version (Einstellungen →
Über) und ob Sie `design.penpot.app` oder einen eigenen Server nutzen.

Bei Fragen zu Ihrem Penpot-Konto oder zu `design.penpot.app` selbst wenden Sie sich an
Penpot unter [help.penpot.app](https://help.penpot.app).

Viewer for Penpot ist eine unabhängige App. Sie stammt nicht von Kaleidos, der Firma hinter
Penpot, und ist weder mit ihr verbunden noch von ihr unterstützt. „Penpot“ ist eine Marke
von Kaleidos.
